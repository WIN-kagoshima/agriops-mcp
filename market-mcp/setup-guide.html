このサーバーは何？

🎯 スグクル特定技能派遣の営業を AI で加速するツール群

Claude や ChatGPT などの AI アシスタントに接続すると、以下のことが自然な日本語で質問するだけでできるようになります：

  • 「鹿児島のさつまいもの今月の市場価格を教えて」→ 参考卸売価格・季節傾向が即座に返る
  • 「愛媛県の市町村別の農業就業人口を一覧で見せて」→ 150 市町村のデータベースから取得
  • 「今月、九州で最も営業すべき市町村を選んで」→ AI がスコアリングして営業トーク例まで自動生成
💡
MCP（Model Context Protocol）は AI アシスタントに外部データソースを接続するための標準規格です。サーバーの URL を設定ファイルに書くだけで AI が自動的にツールを認識します。

1

設定ファイルを開く

Claude Desktop のメニュー → Settings → Developer → Edit Config をクリック。
または直接ファイルを開く：

Windows 
// エクスプローラーのアドレスバーに貼り付け
%APPDATA%\Claude\claude_desktop_config.json
Mac 
~/Library/Application Support/Claude/claude_desktop_config.json

以下の JSON を貼り付ける

既存の設定がある場合は mcpServers の中に追加してください。

claude_desktop_config.json 
{

    "agriops-market": {
      "url": "https://agriops-market-mcp-731026511067.asia-northeast1.run.app/mcp"
    }
  }
}

使えるツール一覧（8つ）
select_dispatch_sales_targets
市場価格 × 労働力減少率 × SSW適性を3軸で統合スコアリングし、派遣営業アタック先の最優先ターゲット市町村を自動選抜。セールストーク例も自動生成。
🔥 NEW — AI営業支援
get_market_price
さつまいも・いちご・トマト・みかん・米・茶・木材など19品目の市場参考卸売価格。月別の季節変動係数付き。
💰 市場価格
get_prefecture_crop_profile
都道府県別の作物プロフィール（主要作物・生産量ランク・SSW適性）を一覧で取得。
📊 統計データ
get_municipality_stats
市町村レベルの農業統計（就業人口・経営体数・主要作物・SSW適性トップ作物）。約150市町村をカバー。
📊 統計データ
get_labor_shortage_stats
農業労働力不足の統計。地域別の就業人口減少トレンドと人手不足深刻度を分析。
📊 統計データ
get_livestock_regional_stats
地域別の畜産統計（ブロイラー・養豚・肉用牛等）。飼養頭数・出荷量データ。
📊 統計データ
get_ssw_crop_compatibility
特定技能外国人（SSW）と作物の適性マッチング。作物ごとの必要スキル・繁忙期・雇用形態を分析。
🤖 AI分析
get_estat_stats
e-Stat（政府統計ポータル）API から農業関連統計を直接取得。※ ESTAT_APP_ID が必要。
📊 統計データ

うまくいかないときは

❌ 「ツールが見つかりません」と言われる

  • URL の末尾に /mcp が付いているか確認してください
  • JSON の構文エラーがないか確認（カンマの過不足など）
  • 設定後、アプリを完全に再起動してください（タスクバーから終了→再起動）

❌ 「接続できません」エラー

  • オフィスの Wi-Fi / VPN で外部アクセスが制限されていないか確認
  • ブラウザで サーバー URL を開いて JSON が表示されるか確認
  • プロキシ環境の場合、ネットワーク管理者に相談してください

❌ 「get_estat_stats が使えない」

  • このツールのみ e-Stat API キー（ESTAT_APP_ID）が必要です
  • 他の 7 ツールは API キーなしで利用可能です
  • e-Stat API キーは e-Stat で無料取得できます
