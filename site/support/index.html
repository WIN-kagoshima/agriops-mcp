日本語

サポートが必要なとき

  • 使い方・ツールの挙動に関する質問 → GitHub Issues で「question」ラベルを付けて投稿してください。
  • 不具合報告 → 再現手順、使用したツール名と入力、期待した結果と実際の結果を含めて GitHub Issues に投稿してください。
  • ドキュメント → README、 docs/ フォルダ、 API リファレンス を参照してください。

脆弱性の報告（セキュリティ）

公開の GitHub Issue は使わないでください。

info@win-g-c.com 宛に、以下を含めてメールしてください:

  • 問題の説明
  • 再現手順（可能であれば最小限のMCPクライアントのやり取りログ）
  • 発生した package.json の version と使用したトランスポート（stdio または streamable-http）
  • 可能であれば対処案

3営業日以内に受領を連絡し、30日以内に修正または対処方法の文書化を目指します。詳細は SECURITY.md を参照してください。

English

When you need support

  • Usage / tool-behaviour questions → open a GitHub Issue with the "question" label.
  • Bug reports → open a GitHub Issue including reproduction steps, the tool name and input you used, and the expected vs. actual result.
  • Documentation → see the README, the docs/ folder, and the API reference.

Reporting a vulnerability (security)

Please do not open a public GitHub issue.

Email info@win-g-c.com with:

  • A description of the issue.
  • Steps to reproduce, ideally with a minimal MCP client transcript.
  • The version (package.json version) and transport (stdio or streamable-http) where you observed it.
  • Any suggested mitigation.

We will acknowledge within 3 business days and aim to ship a fix or a documented mitigation within 30 days. Full hardening notes are in SECURITY.md.

Bahasa Indonesia

Kapan Anda membutuhkan dukungan

  • Pertanyaan penggunaan / perilaku tool → buka GitHub Issue dengan label "question".
  • Laporan bug → buka GitHub Issue yang menyertakan langkah reproduksi, nama tool dan input yang Anda gunakan, serta hasil yang diharapkan vs. hasil aktual.
  • Dokumentasi → lihat README, folder docs/, dan referensi API.

Melaporkan kerentanan (keamanan)

Jangan membuka GitHub issue publik.

Kirim email ke info@win-g-c.com yang berisi:

  • Deskripsi masalah.
  • Langkah reproduksi, idealnya dengan transkrip minimal klien MCP.
  • Versi (version pada package.json) dan transport (stdio atau streamable-http) tempat Anda mengamati masalah tersebut.
  • Saran mitigasi jika ada.

Kami akan mengonfirmasi penerimaan dalam 3 hari kerja dan berupaya merilis perbaikan atau mitigasi terdokumentasi dalam 30 hari. Catatan pengamanan lengkap ada di SECURITY.md.
