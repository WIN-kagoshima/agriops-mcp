Operational requirements

  1. Adapters must populate attribution. Every adapter's result type carries an attribution: string field, copied into structuredContent.attribution so the LLM can quote it when summarising the data to end users.
  2. The MCP Apps UI must display attribution near the data. The dashboard shows attribution in the map footer and in the weather overlay tooltip.
  3. Adding a new data source requires four updates: the canonical doc, .well-known/mcp-server.json data_sources, the adapter implementation with attribution, and a unit test asserting attribution is non-empty.

For the full revision history (when an upstream license changed and how we responded), see the "Revisions" table at the bottom of docs/data-license.md.
