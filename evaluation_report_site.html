Executive Summary

エグゼクティブサマリー

日本初のMCP農業データサーバー

AgriOps MCPは、散らばっていた各種公式オープンデータを高度にパッケージングし、世界標準のModel Context Protocol (MCP)を用いて主要AIエージェントに瞬時に接続する参照実装です。

高い技術的品質を備え、Google Cloud (Cloud Run) でのデプロイ実績もあり、即時の商用展開や本番環境での利用が可能なレベルに達しています。

  • 1

    即時本番利用可能

    すでにCloud Run環境で動作し、極めて堅牢な品質検証プロセスを通過済みです。

  • 2

    他社への高い普及力

    Apache-2.0のクリーンなライセンス形態と、法規に完全準拠した安全な設計により他社が導入しやすい環境が整っています。

  • 3

    最大数ヶ月の工数削減

    仕様がバラバラだった気象・地理・法規データを接続するアダプター構築工数を即座に削減します。

Value Proposition

生み出す体験価値と4つのペルソナ

🚜

田中 誠一 (55歳)

農業人材派遣会社マネージャー

鹿児島の農業人材派遣会社で30名のスタッフを管理。日々の天候に合わせた圃場へのスタッフの配置割りに苦慮しており、手動調整に多くの時間を取られている。

現在の利用ツール
  • 市区町村レベルの天気予報
  • Excelと紙の配置表
  • 電話とLINEでの緊急連絡
⚠ ペインポイント

毎朝5時に起きて、天気サイトと圃場リストを往復。配置の判断とスタッフ調整に30分以上かかり、雨天時の中止判断が遅れて現場が混乱する。

✨ AgriOpsでの次世代体験

「朝起きたら、今日の最適配置がAIからスマホに届いている」
ピンポイントの1km気象リスクをAIが自動分析し、雨天で使用できない畑と作業可能な畑を即時振り分け。判断・連絡の調整時間を30分から2分に短縮します。

📝

山本 あゆみ (32歳)

JA 営農指導員

担当農家80戸。圃場訪問を繰り返し、病害虫への防除や農薬適用の指導、収穫時期のアドバイスを行っている。GIS（地理情報システム）などの高度ITスキルは持たないが、スマホ操作は得意。

現在の利用ツール
  • FAMIC 農薬登録情報提供システム (UIが古く検索しづらい)
  • eMAFF 筆ポリゴン / 地理院地図
  • JA独自の閉じた営農管理システム
⚠ ペインポイント

訪問前に農地地図、警報、農薬の適用基準など4つのシステムを開き、情報集約に1件あたり30分消費。「この農薬使えますか？」の確認に確信が持てない。

✨ AgriOpsでの次世代体験

「訪問先の圃場IDを入力するだけで、瞬時にAIが防除カルテを作成」
`field_visit_checklist` ツールにより、その農地に必要な気象リスク、推奨される適用農薬基準をAIが一瞬で要約。法的安全性を満たした適切なアドバイスを自信を持って即答できます。

🍠

鮫島 隼人 (42歳)

中規模さつまいも農家

3haの畑でさつまいもや茶を栽培。品質管理に厳格で、ブランド化を目指している。水やりや農薬散布のタイミングを、これまでの経験と勘に頼っている。

現在の利用ツール
  • 大まかな天気予報
  • 紙の手帳への作業記録
  • YouTubeでの栽培ノウハウ収集
⚠ ペインポイント

水やりのタイミングや量、農薬を撒くタイミングの科学的な根拠がなく、風の強い日に散布して近隣トラブルになるリスクを抱えている。

✨ AgriOpsでの次世代体験

「畑の状態を話しかけるだけで、科学的データに基づいて答えてくれる」
基準蒸発散量（ET₀）に基づき「今日は畑に〇〇リットルの水やりが必要」とAIが提示。さらに風速・湿度を加味した散布最適時間帯（`spray_window`）を予測し、飛散トラブルをゼロにします。

💻

佐藤 リナ (28歳)

AgriTech スタートアップ CTO

ドローン画像解析や圃場管理の新規SaaSを開発中。自社アプリにAIエージェント機能を組み込み、農家に対して高度な対話型アドバイザーを提供したいと考えている。

現在の利用ツール
  • Open-Meteo REST API
  • 自前でパースするGeoJSONの筆ポリゴンデータ
  • FAMIC Webサイトのスクレイピングモジュール
⚠ ペインポイント

形式がバラバラで複雑な農業データソースを繋ぎ込むアダプター層の開発・メンテナンスだけで2ヶ月以上の工数が消費され、コア機能に集中できない。

✨ AgriOpsでの次世代体験

「MCPのURLを1つ接続するだけで、日本の農業データ基盤が即日手に入る」
標準化されたプロトコルにより、あらゆるLLMモデルに即時に型安全な日本農業データを統合。アダプター層の構築にかかる開発工数を「1日」へと圧縮します。

Managed PaaS

ホスティング＆サポート

自社でサーバーインフラやSQLiteスナップショットのデータ更新（毎週/毎月）を管理する技術を持たないJAや中堅派遣会社に対し、すべてを自動化した環境を提供します。

  • セキュアな専用Cloud Run環境
  • データの自動スナップショット更新保証
  • SLA（稼働率保証）＋テクニカルサポート
🏢

Enterprise SI

カスタムシステム統合

大手農業SaaSプロバイダーや、全国規模の大手人材派遣会社に対し、彼らの基幹システム（独自の日報データ、顧客情報、センサーデータ等）とAgriOps MCPを統合します。

  • 初期設計・インテグレーション開発
  • クローズド環境へのオンプレミス接続
  • 年間保守・運用・アップデートライセンス
Roadmap & Future

今後の飛躍に向けた強化ロードマップ

Phase 1

エコシステムでの露出・マーケティング

Smithery.aiやGlama.aiといった世界的なMCPサーバーディレクトリに正式登録し、公式「Verified Badge」を獲得。GitHub TopicsやDescriptionを最適化し、認知度No.1のポジションを確立する。

Phase 2

有償WAGRIアダプター & 衛星画像連携

オープンデータだけではなく、農研機構が運営する農業データ連携基盤「WAGRI」や、人工衛星「Sentinel-2」の画像解析APIとの有料連携アダプターを開発。AIが土壌の診断や葉色の生育状況も直接把握できる高度データ基盤へ進化。

Phase 3

多言語対応（Global SSW Support）の強化

派遣現場の外国人スタッフの母国語（ベトナム語、インドネシア語、タガログ語等）に対応。AIが防除基準や作業配置スケジュールを各スタッフの母国語へ翻訳し、LINEやチャットツールへ自動連携する機能を強化。
