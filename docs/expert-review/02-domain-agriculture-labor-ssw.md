# 資料 2：農業ドメイン・統計・SSW（特定技能）での意義とリスク

**対象読者**: 農業労働経済、農林業センサス／作物統計／畜産統計に詳しい方、SSW（特定技能）制度や現場派遣オペレーションに詳しい方、保健・労務の観点から夜間作業や外国人材配置を見る専門家

**プロジェクト**: AgriOps MCP — データは **無料公開系**を主に横断し、**経営・派遣の意思決定補助**を目的とする（公的保証や助言ではない）。

---

## 1. 何を「連結」しようとしているか

- **空間・圃場**: eMAFF 系の筆ポリゴン（スナップショット前提）
- **気象**: Open-Meteo、JMA 警告など
- **規制**: FAMIC 農薬登録（利用可能な範囲）
- **市場・作物プロファイル**: 公開市場情報・都道府県プロファイル（ツール化）
- **SSW 戦略層（v1.8〜）**:
  - 作物別の「派遣適性」**スコアリング**（ルーブリック＋説明文）
  - **農林業センサス系**の都道府県労働力統計
  - **畜産統計**に基づく都道府県別畜産プロファイル（ブロイラー「捕鳥」等を強調）
- **市町村ミクロ層（v1.10）**:
  - 展開圏での **主要市町村の内蔵統計**（就業人口・経営体・主要作物・SSW 関連メモ）
  - 地図上のドリルダウン UX と連動

---

## 2. 明示したい前提（誠実さ）

- スコアやランキングは **モデル支援用のヒューリスティクス**であり、**行政・法令上の根拠ではない**。
- 市町村データは **全件網羅ではなく**、初期は展開圏の主要自治体に限定。**圏外は「準備中」**を返す設計。
- **最新の届出・現場ルール**（農薬、防疫、労働時間、特定技能の業務範囲）は、必ず一次情報で確認する必要がある。

---

## 3. レビューしてほしい中核テーマ

1. **統計の出典と解釈**: 農林業センサス 2020・畜産統計 2023 等を「都道府県／市町村・SSW 故事」に結びつけるときの、**誤読しやすい落とし穴**（定義のずれ、比較可能性）
2. **「捕鳥×SSW」 narrative**: 現場の労務・衛生・夜間労働・教育の観点で、プロダクト上の強調が **現実とズレる点**はあるか
3. **季節ローテーション（愛媛・和歌山・徳島など）**: データと物語の両方について、**過剰単純化**に見える箇所
4. **公平性・リスク**: 地域や作物に「優先度ラベル」を付与する UI が、**ステレオタイプや誤った投資判断**を誘発しないか

---

## 4. 求めたいアウトプット

- **赤旗（必ず直すべき）** / **黄旗（注釈で緩和）** / **緑（十分妥当）** の整理
- **追加すべきデータソース**（依然として無料または再配布可能な範囲で）を 3 つまで
- **プロダクトに「倫理・コンプライアンス一文」**を入れるなら、どの表現がよいか
