# 資料 3：プロダクト・「戦略室」UX・導入と価値の伝え方

**対象読者**: B2B プロダクトマネージャー、デザイナー（データプロダクト）、営業戦略、農業法人・JA・派遣の現場オペレーション改善に詳しい方

**プロジェクト**: AgriOps MCP v1.10.2 の **MCP Apps ダッシュボード（戦略室 UI 2.0）**を中心に述べる。

---

## 1. ユーザーシナリオ（想定）

- **ホスト内の LLM** がツールを呼び、結果の `structuredContent` に含まれる **`viz_hint`** に応じて、**インライン UI** が自動でチャート／地図を選ぶ。
- オペレーターが **都道府県 → 市町村** 方向にドリルし、**ブレッドクラム**で戻る。
- **クイックアクション**から全国労働力ビュー、SSW 適性、畜産、市場価格へ素早く切り替え可能。

---

## 2. 差別化の仮説（レビューしてほしい）

1. **「データカタログ」ではなく意思決定の殻**であること — LLM がプロンプト `strategy_room_dashboard` と組み合わせて **次の一手（どのツールをどの順で）**まで誘導できる
2. **マクロ（全国）とミクロ（市町村）**を同一画面体験に載せること
3. **派遣会社の現場語彙**（捕鳥、ローテ、不足度）に寄せたコピーとデータの結合

---

## 3. 既知のトレードオフ

- **ホストが MCP Apps 非対応**のときは HTML ではなくテキスト＋構造化にフォールバック — 価値説明の二重化が必要
- **TopoJSON の精度**はリポジトリ同梱がスタブ寄り — 見せ方として「境界デモ」か「本番 N03 ビルド後」かを切り分ける必要
- **チャートは自前 SVG + MapLibre** — 見栄えは一線級 BI より **軽量・埋め込み**優先

---

## 4. レビュー依頼事項

1. **ペルソナ優先順位**: 経営企画、営業、現場コーディネーター、労務 — 誰を第一利用者にすべきか
2. **10 分デモ**で「刺さる順」の画面遷移案
3. **購入・導入判断者**（派遣会社）に対する **成功指標（KGI/KPI）**の提案
4. **競合・代替**: 汎用 BI、国策ダッシュボード、他スタートアップとの住み分け
5. **ひらめき**: MCP を「社内だけでなく顧客ポータル」に出すときのギャップと克服策
